# CIS Controls v8.1

> Edición: **CIS Critical Security Controls v8.1** (guía `CIS_Controls_Guide_v8.1.2_0325_v2.pdf` en el `Material/` de [[Ethical Hacking]]).

## Qué es

- Conjunto priorizado de **18 controles** de ciberseguridad del Center for Internet Security, divididos en salvaguardas.

## Grupos de implementación

| Grupo | Para quién |
|---|---|
| IG1 | Higiene cibernética básica; toda organización |
| IG2 | Organizaciones con más recursos y datos sensibles |
| IG3 | Organizaciones con equipos de seguridad y riesgos altos |

## Los 18 controles

1. Inventario y control de activos empresariales
2. Inventario y control de activos de software
3. Protección de datos
4. Configuración segura de activos y software
5. Gestión de cuentas
6. Gestión del control de acceso
7. Gestión continua de vulnerabilidades
8. Gestión de registros de auditoría
9. Protección de correo y navegador
10. Defensas contra malware
11. Recuperación de datos
12. Gestión de la infraestructura de red
13. Monitoreo y defensa de la red
14. Concienciación y formación en seguridad
15. Gestión de proveedores de servicios
16. Seguridad del software de aplicación
17. Gestión de respuesta a incidentes
18. Pruebas de penetración
