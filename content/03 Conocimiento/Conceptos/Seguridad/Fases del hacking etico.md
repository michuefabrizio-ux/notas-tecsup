# Fases del hacking ético

## Qué es

- El **hacking ético** evalúa la seguridad de un sistema o red **con autorización**, para reportar las vulnerabilidades antes de un ataque real.

## Cómo funciona

1. **Pre-engagement**: alcance, autorización y reglas de enfrentamiento.
2. **Footprinting y reconocimiento**: información pública (Whois, Google Hacking, subdominios).
3. **Escaneo**: hosts vivos, puertos, servicios, SO y vulnerabilidades.
4. **Enumeración**: usuarios, recursos compartidos y servicios por consultas activas.
5. **Explotación / ganar acceso**: exploits y payloads (Metasploit).
6. **Mantener acceso y post-explotación**.
7. **Reporte**: hallazgos y recomendaciones.

## Metodologías

| Metodología | Enfoque |
|---|---|
| CEH | Fases del hacking (EC-Council) |
| PTES | Estándar de ejecución de pentesting |

| OSSTMM 3 | Metodología abierta de pruebas |
| OWASP WSTG | Aplicaciones web |
| MITRE ATT&CK | Matriz de tácticas y técnicas de atacantes |
