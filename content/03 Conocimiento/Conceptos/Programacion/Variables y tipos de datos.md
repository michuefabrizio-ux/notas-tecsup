# Variables y tipos de datos

## Qué es

- Una **variable** guarda un valor con un nombre; su **tipo** define qué operaciones admite.

| Tipo (Python) | Ejemplo |
|---|---|
| `int` | `stock = 15` |
| `float` | `precio = 25.50` |
| `str` | `codigo = "P001"` |
| `bool` | `activo = True` |

- Conversión: `int("5")`, `float("2.5")`, `str(10)`. Entrada: `input()` siempre devuelve texto.
