# Diagramas de flujo (Entrada–Proceso–Salida)

## Qué es

- Un **algoritmo** es una secuencia finita y ordenada de pasos. Se representa en **pseudocódigo** o **diagrama de flujo**.
- Esquema **EPS**: Entrada (datos) → Proceso (cálculos y decisiones) → Salida (resultados).

## Símbolos

| Símbolo | Uso |
|---|---|
| Óvalo | Inicio / fin |
| Paralelogramo | Entrada o salida |
| Rectángulo | Proceso / asignación |
| Rombo | Decisión |
| Flechas | Flujo |
