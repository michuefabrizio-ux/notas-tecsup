# Modelo TCP/IP

## Comparación con OSI

| TCP/IP | OSI equivalente | Protocolos |
|---|---|---|
| Aplicación | 7, 6, 5 | HTTP, DNS, DHCP, SMTP, FTP |
| Transporte | 4 | TCP, UDP |
| Internet | 3 | IPv4, IPv6, ICMP |
| Acceso a la red | 2, 1 | Ethernet, Wi-Fi |

- Es el modelo que realmente se implementa en Internet; OSI se usa como referencia para explicar y diagnosticar.
