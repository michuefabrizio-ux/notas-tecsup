# Física básica para laboratorio

## Fórmulas de los labs

| Tema | Fórmula |
|---|---|
| Ley de Hooke | `F = k·x` |
| Equilibrio de fuerzas | ΣF = 0; la equilibrante es opuesta a la resultante (método del paralelogramo) |
| Presión / hidrostática | `P = F/A` · `P = ρ·g·h` · empuje `E = ρ·g·V` |
| Reflexión | ángulo de incidencia = ángulo de reflexión (respecto a la normal) |
| Refracción (Snell) | `n1·sen θ1 = n2·sen θ2`; ángulo crítico `sen θc = n2/n1` |
| Calor | `Q = m·c·ΔT` |
| Gas ideal | `P·V = n·R·T`; Boyle: `P1·V1 = P2·V2` (T constante) |
