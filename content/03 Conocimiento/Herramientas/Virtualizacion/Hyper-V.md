# Hyper-V

## Qué es

- Hipervisor tipo 1 de Microsoft incluido en Windows Server (y Windows Pro).

## Conmutadores virtuales

| Tipo | Conecta |
|---|---|
| Externo | VMs con la red física |
| Interno | VMs y el host |
| Privado | Solo VMs entre sí |
