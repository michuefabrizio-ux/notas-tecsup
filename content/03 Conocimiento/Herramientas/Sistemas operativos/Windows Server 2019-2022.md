# Windows Server (2019 / 2022 / 2025)

## Qué es

- Sistema operativo de servidor de Microsoft: AD DS, DNS, DHCP, IIS, Hyper-V, clúster de conmutación por error.
- Modos: **con experiencia de escritorio (GUI)** o **Server Core** (sin GUI, menos recursos, se administra con PowerShell).
