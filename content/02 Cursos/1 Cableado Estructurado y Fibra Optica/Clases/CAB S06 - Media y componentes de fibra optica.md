# CAB S06 — Media y componentes para cableado con fibra óptica

← MOC del curso: [[Cableado Estructurado y Fibra Optica]] · Fuente: `Material/PPT-S06-JVELARDE-2026-02.pdf`

## Tema de la sesión

- Principio de la fibra, partes, longitudes de onda, tipos de fibra y cable, conectores y accesorios.

## Lo esencial

- La luz viaja por **reflexión total interna**: ángulo crítico `sen θc = n2 / n1`.
- **Índice de refracción**: n = c / v (agua 1,33 → la luz va 1,33 veces más lenta).
- Partes: núcleo, revestimiento, buffer, 2.° recubrimiento, aramida, cubierta.
- `λ = c / f`; las comunicaciones ópticas usan "ventanas" (850, 1300/1310, 1550 nm).
- Colores de chaqueta: OM1/OM2 naranja, **OM3 celeste**, **OM4 mora**, **OM5 verde lima** (SWDM), OS amarillo.
- Construcción: **holgada (loose)** con gel, varias fibras, exterior; **ajustada (tight)**, fácil de terminar, interior.
- Cables aéreos (figura 8, ADSS, OPGW), subterráneos (acero corrugado) y submarinos (> 95 % del tráfico mundial).
- Conectores, acopladores, **pigtail**, **patch cord**, bandejas, cajas y mufas.
